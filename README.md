## Project Overview

This project demonstrates the implementation of various MongoDB operations on a dataset containing **50 student records**.

The practical focuses on performing CRUD operations and using MongoDB features such as filtering, sorting, and limiting the number of returned documents.

## Operations Performed

* **Create** – Inserting student records into MongoDB
* **Read** – Retrieving and displaying student records
* **Update** – Modifying existing student records
* **Delete** – Removing student records
* **Filtering** – Retrieving records based on specified conditions
* **Sorting** – Arranging records in ascending or descending order
* **Limit** – Restricting the number of documents returned

## Dataset

The practical uses a dataset consisting of **50 student records**. The dataset is used to demonstrate the different MongoDB queries and operations included in this project.
